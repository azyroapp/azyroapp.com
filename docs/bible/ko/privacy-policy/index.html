개인정보 처리방침

최종 업데이트: 2026년 4월 6일

AzyroApp에서는 개인정보 보호가 기본적인 권리라고 믿습니다. 이 개인정보 처리방침은 성경 앱이 귀하의 정보를 어떻게 처리하는지 설명합니다. 우리는 개인정보 보호를 핵심으로 성경을 설계했습니다 — 귀하의 개인 데이터는 기기에 남아 있으며, 수집, 판매 또는 공유할 의도가 없습니다.

📖 성경 앱에 대하여

성경은 AzyroApp이 개발한 모바일 애플리케이션으로, 하나님의 말씀을 읽고, 공부하고, 나눌 수 있게 해줍니다. 앱에는 여러 언어의 다양한 성경 버전, 즐겨찾기, 핀, 읽기 진행률 추적, 고급 구절 검색 등의 읽기 도구가 포함되어 있습니다.

성경은 기기에서 독립적인 도구로 작동하도록 설계되었습니다. 계정이 필요하지 않으며, 핵심 기능을 위해 외부 서버에 연결하지 않고, 개인 정보를 수집하지 않습니다.

🔒 개인정보 보호에 대한 약속

성경은 개인정보 보호 우선 아키텍처로 구축되었습니다. 이는 다음을 의미합니다:

  • 모든 데이터 — 즐겨찾기, 핀, 읽기 진행률, 환경설정 및 설정 — 은 기기에 로컬로 저장됩니다
  • 앱은 사용자 등록이나 계정 없이 작동합니다
  • 외부 서버에 개인 정보를 수집, 전송 또는 저장하지 않습니다
  • 분석, 추적 픽셀 또는 행동 모니터링을 사용하지 않습니다
  • 어떤 종류의 광고도 표시하지 않습니다
  • 사용자 프로필을 만들거나 읽기 습관을 추적하지 않습니다

간단히 말해: 성경 앱에서 하는 모든 것은 기기에 남습니다. 우리는 볼 수 없고, 보고 싶지 않으며, 절대 볼 수 없도록 앱을 만들었습니다.

💾 기기에 저장되는 데이터

다음 데이터는 iPhone에서만 생성되고 저장됩니다:

읽기 데이터

  • 북마크한 즐겨찾기 구절
  • 구절에 추가한 핀
  • 읽음으로 표시한 장과 진행률 통계
  • 선택한 성경 버전 환경설정

앱 환경설정

  • 글꼴 크기 및 표시 설정
  • 색상 테마 환경설정
  • 알림 설정 및 일정
  • 언어 환경설정

구매 정보

  • 구독 또는 구매 상태는 기기의 암호화된 키체인에 저장됩니다
  • 프리미엄 콘텐츠 잠금 해제 여부를 결정하는 데만 사용됩니다
  • 결제 세부정보, 신용카드 번호 또는 청구 정보를 저장하지 않습니다

☁️ iCloud 동기화

기기에서 iCloud가 활성화되어 있으면, 성경 앱은 Apple의 NSUbiquitousKeyValueStore를 사용하여 Apple 기기 간에 데이터를 동기화합니다:

  • 즐겨찾기, 핀, 읽기 진행률 및 통계가 동기화됩니다
  • 동기화는 Apple의 iCloud 인프라에서 완전히 처리됩니다
  • AzyroApp은 이 데이터를 수신하는 서버를 운영하지 않습니다
  • Apple ID를 통해 본인만 iCloud 데이터에 접근할 수 있습니다
  • 기기 설정에서 언제든지 iCloud 동기화를 비활성화할 수 있습니다

🔔 알림

권한을 부여한 경우 성경은 로컬 알림을 보낼 수 있습니다:

  • 선호하는 시간에 매일 읽기 알림
  • iOS에서 기기에서 완전히 생성되는 알림
  • 알림 데이터는 외부 서버로 전송되지 않습니다
  • iOS 설정 → 알림 → 성경에서 언제든지 관리하거나 비활성화할 수 있습니다

💳 구매, 구독 및 결제

성경은 Apple App Store에서 완전히 관리하는 인앱 구매를 통해 프리미엄 콘텐츠를 제공합니다:

  • 모든 거래는 Apple이 App Store를 통해 처리합니다
  • AzyroApp은 결제 정보를 수신, 처리 또는 저장하지 않습니다
  • 신용카드 번호, 청구 주소 또는 금융 데이터에 접근할 수 없습니다
  • 구매 확인은 Apple의 StoreKit 2 프레임워크를 사용합니다

🚫 수집하지 않는 정보

  • 개인 식별자: 이름, 이메일, 전화번호 또는 주소를 수집하지 않습니다
  • 기기 식별자: 기기 ID, IDFA 또는 하드웨어 식별자를 수집하지 않습니다
  • 위치 데이터: 지리적 위치에 접근하지 않습니다
  • 사용 분석: 어떤 구절을 읽는지 추적하지 않습니다
  • 오류 보고서: 오류 로그를 수집하지 않습니다
  • 네트워크 정보: IP 주소나 연결 유형을 수집하지 않습니다
  • 연락처 또는 미디어: 연락처, 사진 또는 카메라에 접근하지 않습니다

🛡️ 데이터 보안

데이터를 수집하지 않지만, 로컬에 저장된 데이터의 보안을 중요하게 생각합니다:

  • 민감한 데이터는 하드웨어 수준 암호화를 사용하는 Apple 키체인에 저장됩니다
  • 앱은 네트워크를 통해 데이터를 전송하지 않습니다 (Apple이 관리하는 iCloud 동기화 및 구매 확인 제외)
  • iOS 앱 개발을 위한 Apple의 보안 모범 사례를 따릅니다

👶 아동 개인정보 보호

성경은 App Store에서 4+로 분류되어 모든 연령에 적합합니다. 어떤 사용자로부터도 개인 정보를 수집하지 않으므로 아동 데이터 수집 위험이 없습니다. 앱에는 사용자 생성 콘텐츠나 소셜 기능이 포함되어 있지 않습니다.

🗑️ 데이터 삭제 및 제어

  • 로컬 데이터: 앱을 삭제하면 모든 데이터가 영구적으로 삭제됩니다
  • iCloud 데이터: 설정 → [이름] → iCloud → 저장 공간 관리 → 성경
  • 구독: 설정 → [이름] → 구독 → 성경

서버에 데이터를 저장하지 않으므로 삭제 요청을 보낼 필요가 없습니다.

🌍 국제 사용자

성경은 전 세계에서 사용할 수 있습니다. 개인 데이터를 수집, 처리 또는 전송하지 않으므로 국경 간 데이터 전송에 대한 우려가 없습니다. 동일한 개인정보 보호가 모든 사용자에게 동등하게 적용됩니다.

📱 제3자 서비스

성경 앱은 다음 Apple 서비스만 통합합니다:

  • Apple StoreKit 2: 인앱 구매 처리. Apple이 관리.
  • Apple iCloud: 선택적 데이터 동기화. Apple이 관리.
  • Apple AVFoundation: 텍스트 음성 변환. 기기에서 처리.

제3자 분석 서비스, 광고 네트워크 또는 소셜 미디어 플랫폼과 통합하지 않습니다.
