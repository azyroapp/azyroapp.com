서비스 약관

최종 업데이트: 2026년 4월 6일

성경에 오신 것을 환영합니다. 이 서비스 약관은 AzyroApp이 개발한 성경 모바일 애플리케이션의 사용을 규정합니다. 앱을 다운로드, 설치 또는 사용함으로써 이 약관에 동의하게 됩니다.

📖 서비스에 대하여

성경은 개인 읽기, 공부 및 공유를 위해 여러 버전의 성경에 접근할 수 있는 모바일 애플리케이션입니다.

  • 25개 이상의 언어로 50개 이상의 성경 버전 포함
  • 모든 텍스트는 공개 도메인 또는 무료 사용
  • 초기 다운로드 후 주로 오프라인으로 작동
  • 어떤 종교 단체와도 제휴하지 않음

📚 콘텐츠 및 접근 수준

무료 콘텐츠

  • 모든 버전에서 창세기 전체 접근
  • 창세기 내 모든 앱 기능

프리미엄 콘텐츠

  • 모든 책 전체 접근
  • 모든 책에서 전체 검색
  • 구독 또는 일회성 구매로 이용 가능

💳 구독 및 구매

구독 플랜

  • 월간 구독: 매월 자동 갱신 프리미엄 접근
  • 연간 구독: 할인된 요금으로 매년 자동 갱신

일회성 구매

  • 구매 시점의 프리미엄 콘텐츠에 접근하는 단일 결제
  • 향후 주요 업데이트는 별도 구매로 제공될 수 있음

자동 갱신

  • 확인 시 Apple ID 계정에서 결제
  • 기간 종료 24시간 전까지 비활성화하지 않으면 자동 갱신

관리 및 취소

  • iOS 설정 → [이름] → 구독에서 관리 또는 취소
  • 취소는 현재 기간 종료 시 적용
  • 환불은 Apple이 reportaproblem.apple.com에서 독점 관리

다음 목적을 위한 제한적, 비독점적, 양도 불가능한 라이선스가 부여됩니다:
